# المنصة الرقمية الموحدة لإدارة الإغاثة والتنمية - جمعية تطوير بيت لاهيا (BLDA)
### مشروع تخرج جامعي متميز • قطاع غزة

منصة ويب متكاملة مبنية باستخدام **Next.js 14** و **Tailwind CSS** وقاعدة بيانات **Supabase (PostgreSQL)**، مصممة لإدارة وتنسيق العمليات الإغاثية وخدمة النازحين والمتضررين في مخيمات قطاع غزة بكل شفافية وعدالة وموثوقية.

---

## 🌟 مميزات المنصة الرئيسية

1. **بوابة المستفيدين واستمارة الإغاثة الفورية:**
   - تسجيل بيانات أرباب الأسر، الهويات (مع التحقق من صحة الرقم 9 خانات)، وأرقام التواصل.
   - تحديد المخيم ونقطة التواجد الميدانية وطبيعة المأوى (خيام، مراكز إيواء).
   - رصد الحالات الحرجة (جرحى، أيتام، ذوو احتياجات خاصة، ورضع).
   - **توليد كود تتبع فوري فريد (Tracking Code)** مثل `BLDA-94120` يحفظه المستفيد لمتابعة طلبه دون الحاجة لكلمة مرور.

2. **نظام الفحص والمتابعة اللحظية (Live Request Tracking):**
   - استعلام مباشر برقم الهوية أو كود التتبع.
   - شريط زمني تفاعلي يبين مرحلة الطلب (استلام، تدقيق، اعتماد وتجهيز، تسليم ميداني).
   - عرض ملاحظات الباحث الميداني وتفاصيل نقطة التوزيع.

3. **لوحة التحكم المركزية للباحثين والإدارة (Admin Dashboard):**
   - مؤشرات وإحصائيات رقمية مباشرة لحجم الطلبات والاستحقاق.
   - تصفية متقدمة حسب المخيم ودرجة الأولوية وحالة الصرف.
   - تحديث حالة الطلبات بنقرة زر واحدة (قيد المراجعة ⬅️ معتمد ⬅️ قيد التجهيز ⬅️ تم التسليم).
   - **تصدير كشف التوزيع إلى ملف Excel / CSV** باللغة العربية بضغطة زر لاستخدامه من قِبل طواقم التوزيع الميداني.

4. **تكامل كامل مع Supabase و Vercel:**
   - قاعدة بيانات PostgreSQL سحابية متوافقة مع سياسات الأمان والحماية (Row Level Security - RLS).
   - تشغيل هجين وذكي: يعمل الموقع بكامل وظائفه محلياً وخلال المناقشة حتى قبل إدخال المفاتيح، ويتصل تلقائياً بـ Supabase عند ضبط المتغيرات.

## 🏗️ المعمارية التقنية (Tech Stack)

- **الواجهة الأمامية (Frontend):** Next.js 14 (App Router) + React 18 + Tailwind CSS.
- **الخلفية ومسارات الخادم (Backend):** Serverless API Routes (Node.js / Next.js) + Supabase Client SDK.
- **قاعدة البيانات (Database):** Supabase Cloud (PostgreSQL) مع ملف `database/schema.sql` الجاهز.
- **التصميم والأيقونات:** Tailwind CSS (ألوان وهوية بيت لاهيا الخضراء) + Lucide React + خطوط عربية مريحة (Tajawal & Cairo).
- **الاستضافة والنشر (Hosting):** Vercel + مستودع GitHub.

## 🗄️ إعداد قاعدة بيانات Supabase خطوة بخطوة

1. توجه إلى [Supabase](https://supabase.com) وأنشئ حساباً ومشروعاً جديداً مجانياً.
2. من القائمة الجانبية، ادخل إلى **SQL Editor**.
3. افتح ملف `database/schema.sql` الموجود داخل هذا المشروع، وانسخ محتواه والصقه داخل محرر SQL في Supabase ثم اضغط **Run**.
4. سيتم إنشاء كافة الجداول (المخيمات، المستفيدين، الطلبات، الحملات، الرسائل، وسياسات RLS) مع البيانات الأولية.
5. من إعدادات المشروع في Supabase (**Project Settings ⬅️ API**):
   - انسخ **Project URL**
   - انسخ **anon public key**
6. أنشئ ملفاً باسم `.env.local` في مجلد المشروع الرئيسي وضع فيه:
```env
NEXT_PUBLIC_SUPABASE_URL=رابط_مشروعك_هنا
NEXT_PUBLIC_SUPABASE_ANON_KEY=مفتاح_anon_هنا
```

## 🌐 دليل النشر على GitHub و Vercel

### أولاً: الرفع على مستودع GitHub
```bash
git init
git add .
git commit -m "الإصدار الأول - منصة جمعية تطوير بيت لاهيا للإغاثة"
git branch -M main
git remote add origin https://github.com/اسم_حسابك/اسم_المستودع.git
git push -u origin main
```

### ثانياً: النشر المجاني عبر Vercel
1. ادخل إلى موقع [Vercel](https://vercel.com) وسجل دخولك بحساب GitHub.
2. اضغط على **Add New... ⬅️ Project**.
3. اختر مستودع المشروع واضغط **Import**.
4. في قسم **Environment Variables** أضف المتغيرين:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. اضغط **Deploy**. في غضون دقيقة سيكون موقعك متاحاً برابط عالمي سريع ومجاني!
